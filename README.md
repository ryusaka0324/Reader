# 栞読 - TXT Reader PWA

スマホで長文TXTを読むための、ビルド不要のPWAです。GitHub Pagesにそのまま置けます。

## 主な機能

- 本棚を「作品 → 部・期・巻 → 話」の3階層で管理
- TXT追加時に作品名、部・期、話タイトル、並び順を指定
- ファイル名から本棚情報を簡易推定
- 追加後も各話の「編集」から別作品・別期へ移動可能
- 各話の読書進捗を本棚に表示
- TXTファイル読み込み（UTF-8 / Shift_JISを簡易判定）
- 横読み / 縦読みの切り替え
- 読書位置を段落単位で自動保存
- しおりを複数保存、任意メモ付き
- 文字サイズ、行間、余白、背景テーマ調整
- 見出しの簡易自動検出と目次
- 読み込んだ本文をIndexedDBへ保存
- Service Workerによるオフライン利用
- iPhone / Androidのホーム画面追加に対応

## 本棚データ

1つのTXTを1つの「話」として保存します。各話は次の情報を持ちます。

- 作品名：例 `魔法少女戦争`
- 部・期・巻：例 `第23期`、`ドイツ編`、`本編`
- 話タイトル：例 `第一話 放課後`
- 並び順：例 `1`

作品や部・期は独立した空フォルダとしてではなく、所属する話から自動的に構成されます。そのため、各話の「編集」で作品名や部・期を変更すると、その場で本棚構造も組み替わります。

旧バージョンですでに保存したTXTは、データを消さずにv2の本棚形式へ自動移行します。

## GitHub Pagesへの公開

1. このフォルダの中身をGitHubリポジトリへアップロードします。
2. GitHubの `Settings > Pages` を開きます。
3. `Build and deployment` で `Deploy from a branch` を選びます。
4. `main` ブランチ / `/ (root)` を選んで保存します。
5. 表示されたPages URLへスマホからアクセスします。
6. iPhoneではSafariの共有ボタンから「ホーム画面に追加」、Androidではブラウザの「アプリをインストール」等を選びます。

## データ保存について

本文、作品・期・話の分類、読書位置、しおり、表示設定はブラウザ端末内のIndexedDBに保存されます。サーバーへ本文を送信しません。

ブラウザのサイトデータを削除すると、本棚やしおりも消えます。同期・エクスポート/インポートは今後の拡張候補です。

## サンプル

`samples/01_天王寺剛花_第一話_放課後.txt` を同梱しています。トップ画面の「同梱サンプルを開く」で `天王寺剛花 → 本編 → 第一話 放課後` として登録されます。


## GitHubスマホアップロード用（フラット構成）

この配布版は、すべてのファイルをリポジトリ直下に置く構成です。`icons/` や `samples/` フォルダは不要です。ZIP展開後に表示されるファイルをすべて GitHub リポジトリ直下へアップロードしてください。
